# ERP Feature List

## Portals

| Portal | Description |
| --- | --- |
| Student | Student-facing academic, fee, and communication tools |
| Teacher | Teaching, classroom, examination, and payroll tools |
| Admin | Institution-wide administration and configuration |
| Admin-Finance | Fee collection, concessions, and payroll operations |
| Higher Authority | Executive access for principals, directors, chairpersons, and trustees |
| Custom User | Role-based access configured for specific operational needs |

## 1. Student Portal

| Area | Features |
| --- | --- |
| Dashboard | Dashboard; assigned classroom details; attendance overview; daily and weekly timetable; fee summary; hostel details (shown when a hostel is allotted); transportation and route details |
| Study / Academics | Syllabus; online live classes; digital library; homework and assignments; class notes and study materials |
| Examinations | Examination schedule and datesheet; examination syllabus; online examination interface; results and report cards (online and offline) |
| Fees & Payments | Fee ledger and summary; online fee payment (school, hostel, and transport); payment history and digital receipts |
| Communication & Notifications | School announcements and circulars; class-specific notices; event broadcasts |
| Institution & General | About the school / institution; event media gallery; interactive forms (surveys, feedback, polls, and event registrations); student leave application |

## 2. Teacher Portal

| Area | Features |
| --- | --- |
| Dashboard | Dashboard; assigned classrooms overview; attendance tracker (self and assigned classes); teaching schedule and timetable; payroll snapshot; transport route details |
| Classroom Management | Classroom roster and student records; assignment creation and grading; online class hosting and scheduling; lecture notes and resource uploads; class notice dispatch |
| Finance | Personal payroll details and payslip history; student fee defaulter / status tracking |
| Examinations | Online examination creation and monitoring; offline examination marks entry; student performance analytics; exam-specific syllabus publishing |
| Institution & General | Institutional information and directory; event media gallery; announcements and circulars; institutional forms and polls; event notifications; leave management (personal leave application and student leave approval) |

## 3. Admin Portal

| Area | Features |
| --- | --- |
| Analytics Dashboard | Institution-wide attendance analytics; academic performance analytics; financial and revenue analytics; admission and enquiry analytics |
| Administrative Management | User profile management (students, staff, and parents); classroom and section setup; admission and enquiry lifecycle management; biometric and facial-recognition attendance integration; staff and student leave policy management; notification engine (circulars, notices, and emergency alerts); transport and fleet management; hostel and dormitory management; custom form builder (surveys, feedback, and polls); media gallery management |
| Financial Management | Counter fee collection and receipt issuance; payroll engine and payslip generation; fee structure configuration (class, batch, and quota-wise) |
| Academic Administration | Online class platform configuration; digital library master management; homework and assignment oversight; lecture repository management; master timetable scheduling engine; institutional profile and handbook setup |
| Examination Management | Offline examination setup, datesheets, and results publication; online examination configuration, question banks, and proctoring; automated report card generation; multi-channel report card dispatch (including WhatsApp integration) |

## 4. Admin-Finance Portal

| Area | Features |
| --- | --- |
| Fee Operations | Real-time collection dashboard and defaulter tracking; counter fee collection (cash, card, POS, cheque, and DD); concessions, waivers, and scholarship management; fee structure setup (class, batch, term, and head-wise); late fee rules and fine automation |
| Payroll Operations | Attendance-linked salary computation; payslip generation and bulk disbursement file export; statutory deductions and tax handling (PF, ESI, and TDS) |

## 5. Higher Authority (HA) Portal

*For principals, directors, chairpersons, and trustees.*

| Area | Features |
| --- | --- |
| Executive Dashboard | Academic performance and accreditation analytics; institutional attendance heatmaps (staff and student trends); financial KPI dashboard (revenues, receivables, and burn rate) |
| Executive Administration & Control | Administrative account provisioning, auditing, and deactivation; budget allocation, departmental budgets, and expense approval; executive directives and institution-wide announcements; senior staff attendance, leave approvals, and faculty retention oversight; full system-wide access and override privileges (equivalent to Master Admin) |

## 6. Custom User Portal (Role-Based Access Control)

| Area | Features |
| --- | --- |
| Role Configuration | Configurable role templates for dedicated functions (e.g., hostel warden, transport coordinator, receptionist, librarian, and inventory manager) |
| Permissions | Granular read / write permissions tailored strictly to operational mandates |

## 7. Global / Cross-Portal Core Capabilities

| Capability | Description |
| --- | --- |
| Integrated Multi-Role Chat System | Role-governed communication network connecting students, teachers, parents, and administrative staff |
| Public Web Portal / Landing Page | Responsive public front end with an integrated authentication gateway |
| Digital Library & Inventory Management | Barcode / RFID asset cataloging, check-out / return workflows, and inventory tracking |
